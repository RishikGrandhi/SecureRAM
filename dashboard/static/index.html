Security boundary & observation limits

This dashboard adds usability and observability. It does not strengthen the cryptography. There is no same-unit, same-generation replay prevention, whole-request atomic plaintext-release guarantee, malicious root/kernel/hypervisor protection, crash-persistent anti-replay, or physical RAM-erasure guarantee.

The local session token does not replace OS privilege isolation. Status and statistics are separate snapshots. Counters survive destroy/rekey, reset on module reload and saturate at U64_MAX. Lock retains the resident keys; destroy discards the volatile medium. Closing this page or stopping the dashboard does not destroy a key.
